CIDR Block IP Calculator

Calculate total and usable IPv4 addresses for a CIDR block.

Enter a CIDR value from /16 through /28.

/
Calculation:

The total number of IPv4 addresses in a CIDR block is calculated using the formula:
2^(32 - CIDR)

For example, for a CIDR block of /16:
2^(32 - 16) = 2^16 = 65,536 total IP addresses.

The calculator reserves 5 IP addresses, which includes the network address, broadcast address, and other reserved addresses.

Therefore:
65,536 - 5 = 65,531 usable IP addresses.

The same calculation is applied to any CIDR value from /16 through /28.
